# docker-tutorial

learn docker with practicals

### lesson 1

Covers running a simple Node.js app inside a Docker container: writing a minimal `hello-docker.js` script, containerizing it with a `Dockerfile` (`FROM node:alpine`), building the image with `docker build`, and running it with `docker run` to confirm the "Hello Docker" output. See [lesson-1/lesson-1.md](lesson-1/lesson-1.md) for the full walkthrough.
